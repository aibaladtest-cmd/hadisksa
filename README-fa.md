# اپلیکیشن حدیث کسا — آماده‌سازی Android و iOS با GitHub Actions

این پروژه با Capacitor 8 آماده شده و دو گردش‌کار GitHub Actions دارد.

## فایل‌های خروجی

- **Android APK آزمایشی:** پس از اجرای گردش‌کار `Build Android APK` از بخش Actions > اجرای موفق > Artifacts قابل دریافت است. این APK از نوع Debug است و برای تست و نصب مستقیم مناسب است؛ برای انتشار عمومی در فروشگاه‌ها باید نسخه Release امضاشده ساخته شود.
- **iOS Simulator App:** گردش‌کار `Build iOS Simulator App` یک برنامه برای شبیه‌ساز iOS می‌سازد. این فایل روی آیفون واقعی نصب نمی‌شود و IPA قابل انتشار نیست.

## شروع کار در GitHub

1. این پوشه را از حالت ZIP خارج کنید.
2. یک Repository جدید در GitHub بسازید.
3. تمام محتویات این پوشه، از جمله پوشه مخفی `.github` را در ریشه Repository بارگذاری کنید.
4. وارد تب **Actions** شوید و در صورت درخواست، گزینه فعال‌سازی GitHub Actions را بزنید.
5. گردش‌کار `Build Android APK` را اجرا کنید. برای iOS نیز `Build iOS Simulator App` را اجرا کنید.
6. بعد از پایان موفق، در صفحه اجرای Workflow بخش **Artifacts** فایل خروجی را دریافت کنید.

## ساخت IPA قابل نصب روی آیفون واقعی

برای تولید IPA امضاشده و قابل نصب/انتشار، به شناسه Bundle نهایی، عضویت Apple Developer، گواهی Distribution و Provisioning Profile معتبر نیاز است. این اطلاعات باید به‌صورت GitHub Actions Secrets تنظیم شوند و گردش‌کار انتشار iOS با روش امضای انتخابی پیکربندی شود. هیچ گواهی یا رمز اپل داخل این مخزن قرار ندهید.

## شناسه برنامه

شناسه فعلی در `capacitor.config.json` برابر `com.abrar.hadithkisa` است. پیش از انتشار نهایی، باید مطمئن شوید این شناسه در حساب‌های انتشار شما آزاد و متعلق به شماست؛ در صورت نیاز آن را تغییر دهید.

## نکات مهم پیش از انتشار

- فایل‌های صوتی و تصویری و رفتار همگام‌سازی متن و صوت باید روی دستگاه واقعی Android و iPhone آزمایش شوند.
- در README اصلی پروژه به بارگذاری فونت‌ها از اینترنت اشاره شده است؛ برای عملکرد کاملاً آفلاین، فایل فونت‌ها باید داخل پروژه قرار بگیرند.
- پخش صوت در پس‌زمینه و هنگام قفل بودن صفحه، به‌خصوص در iOS، نیازمند تنظیم و آزمایش جداگانه Background Audio است.
- این Workflowها پروژه بومی Android و iOS را در زمان اجرا ایجاد می‌کنند؛ بنابراین پوشه‌های `android` و `ios` در ZIP اولیه موجود نیستند.
